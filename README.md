# C10l Taps

## How do I install these formulae?

`brew install c10l/taps/<formula>`

Or `brew tap c10l/taps` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "c10l/taps"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
