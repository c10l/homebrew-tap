# C10l Tap

Custom [Homebrew](https://brew.sh) tap.

## How do I install these formulae?

`brew install c10l/tap/<formula>`

Or `brew tap c10l/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "c10l/tap"
brew "<formula>"
```

> [!NOTE]
> These formulae have no bottles yet, so Homebrew builds them from source and
> installs any required toolchain (e.g. `rust` for `keydo`) as a build dependency.

## Available formulae

| Formula | Description |
| ------- | ----------- |
| `keydo` | Keyboard remapping daemon with layers, overloads and chords |
